# HR Analytics Dashboard: Power BI Data Analysis Project

## Project Overview

![Project Pipeline](https://github.com/Anuraj-cyberfreak01/HR_Analytics_Project/blob/main/hr_analytics.png)

This project is an interactive **HR Analytics Dashboard built using Microsoft Power BI**.

The purpose of this project is to transform raw employee data into meaningful HR insights using data cleaning, transformation, data modeling, DAX calculations, and interactive data visualization.

The dashboard provides an overview of employee demographics, departments, recruitment sources, employment status, termination reasons, performance, salary, and individual employee information.

This project demonstrates practical skills in **data analytics, Power BI, Power Query, DAX, data visualization, and dashboard development**.

---

## Project Steps

### 1. Set Up the Project Environment

* **Tool Used**: Microsoft Power BI Desktop
* **Dataset**: Employee/HR dataset
* **Goal**: Create an interactive HR analytics dashboard from raw employee data.

The project was organized into separate components for:

* Dataset
* Power BI dashboard
* Dashboard screenshots
* Project documentation

---

### 2. Import the HR Dataset

* Import the employee dataset into **Power BI Desktop**.
* Review the available columns and understand the structure of the data.
* Identify important fields related to employee demographics, employment, recruitment, salary, and performance.

The dataset contains information such as:

* Employee Name
* Department
* Position
* Gender
* Marital Status
* Date of Birth
* Joining Date
* Manager

* Employment Status

### 3. Explore the Data

The dataset was explored to understand:

* Number of employees
* Departments
* Employee demographics
* Employment statuses
* Recruitment sources
* Termination reasons
* Salary information
* Performance ratings

The exploration helped identify the fields required to build meaningful HR visualizations.

---

### 4. Data Cleaning and Transformation

Data preparation was performed using **Power Query** in Power BI.

The main transformation steps included:

* Checking for missing values
* Removing unnecessary columns
* Removing duplicate records where required
* Correcting data types
* Formatting date fields
* Cleaning categorical values
* Preparing fields for visualization
* Validating the transformed dataset

The objective was to create a clean and consistent dataset before building the dashboard.

---

### 5. Data Modeling

The cleaned data was structured in Power BI to support efficient analysis and visualization.

The data model was designed to allow analysis across different HR dimensions such as:

* Department
* Gender
* Marital Status
* Employment Status
* Recruitment Source
* Termination Reason
* Race
* Employee
* Performance
* Salary

---

### 6. DAX Calculations

DAX was used to create calculated measures and support dashboard analysis.

Examples of analytical calculations include:

* Employee Count
* Employee distribution
* Salary-related calculations
* Performance-related calculations
* Department-level analysis

DAX measures were used where necessary to make the dashboard interactive and dynamically respond to filters and slicers.
